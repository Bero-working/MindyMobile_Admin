## Nguồn hiện có và cách dùng legacy

Người dùng cung cấp checkout backend `D:/FPT_University/FA26/WDP301/Mindy-BE`:

- [BE business overview](../../../Mindy-BE/docs/api_flow/BE_BUSINESS_OVERVIEW_VI.md) và [docs/api_flow](../../../Mindy-BE/docs/api_flow): ngữ cảnh nghiệp vụ; có file chứa log lịch sử, không dùng một đoạn cũ làm contract hiện tại.
- [postman](../../../Mindy-BE/postman): collections hiện có ở nguồn; chưa nhập bản sao vào mobile.
- Swagger tại `/docs` nếu SWAGGER_ENABLED bật, theo [setup-swagger.ts](../../../Mindy-BE/src/setup-swagger.ts). Chưa xác minh Swagger runtime tại URL người dùng cung cấp.
- Controller/service/domain/DTO trong source là căn cứ implementation hiện tại; không có nghĩa server đang chạy cùng build/migration.

Khi tới bước nhập legacy đã được cho phép, lưu **nguyên byte** tài liệu/collection/OpenAPI được cung cấp vào `legacy/` cùng thông tin nguồn, ngày và SHA-256 ở index ngoài bản gốc; không format, sửa ví dụ hoặc sửa endpoint trong file legacy. Nguồn đổi thì nhập phiên bản mới có nhận diện, không ghi đè âm thầm. Không sao chép .env, secret hoặc token vào docs. Đây là quy trình dự kiến, chưa thực hiện lần này.

Đối chiếu flow → controller (method/path/roles/guards) → DTO → service/domain → contract runtime khi có môi trường. Nếu khác nghiệp vụ người dùng đã xác nhận, ghi khoảng trống + ảnh hưởng + ADR Proposed, dừng phần phụ thuộc; phần độc lập vẫn tiếp tục trong cổng được duyệt. Không bịa endpoint hoặc báo mock là tích hợp xong.

## Host, prefix, cookie và header

Người dùng cung cấp **host local** `http://localhost:3003`. Backend source configure-app đặt global prefix `api` và URI version `v1`. Các đường trong bảng dưới là phần sau `/api/v1`; chưa chốt API_URL nên không tự ghép hoặc bỏ prefix ở code.

Ví dụ khảo sát source: host + `/api/v1/auth/login`; đây không phải bằng chứng endpoint runtime đang hoạt động. File .env backend đọc có chọn lọc ghi PORT=3000, COOKIE_SECURE=true và Origin allowlist có http://localhost:3001; có thể runtime/proxy khác. Không sửa .env hoặc lấy ví dụ env làm cấu hình thiết bị. Q-ENV-01 cần chốt mapping cổng, đường truy cập Android, HTTP debug/HTTPS và Origin được phép.

Auth source dùng access_token HttpOnly path / và refresh_token HttpOnly path /api/v1/auth/refresh, refresh rotation. Những route material/note/meeting và một số P1 route có Origin guard; không suy ra mọi route cùng CSRF/header. `withCredentials` không thay cho cookie jar native đã kiểm chứng. Cách xử lý cookie/refresh/logout/secure storage phải có ADR Auth sau khi đọc legacy. Không lưu token trong MMKV hoặc suy từ HTTP boilerplate đang có Bearer.

Mutation không đồng nhất: attendance dùng expectedVersion + UUID v4 key, material dùng expectedRevision, note dùng version riêng (khởi đầu 0), leave dùng request/source versions. CASH confirm không nhận expectedVersion/key. Hợp đồng từng UI phải giữ khác biệt đó.

## Nội dung bắt buộc của mỗi contract UI sau này

File `<ui-slug>.md` chỉ được tạo sau khi có design và nguồn legacy phù hợp:

1. Slice/BR/UC và link design thật; nguồn legacy cụ thể (file/phiên bản/hash), controller/service/DTO làm căn cứ.
2. Method/path, role/scope/capability, cookie/Origin/header và pagination/filter; không giả quyền dựa trên tên namespace.
3. Request/response DTO TypeScript đúng wire, zod schemas và kiểu z.infer; optional/null/decimal string/date-only giữ đúng nghĩa. Không any/unknown tường minh hoặc schema bỏ validate.
4. Mapping DTO → view model cho design: label/permission/state, timezone/tiền/score, legacy missing/UNTRACKED và toàn bộ trạng thái UI.
5. Error codes thực tế và hành vi từng lỗi; network/timeout, 401/403/404/409/422/5xx, requestId; phân biệt code business/version/state.
6. Query key factory cụ thể, scope account/role/resource/filter/page, cache/invalidate/optimistic rollback, data retention theo policy được duyệt.
7. expectedVersion/revision, Idempotency-Key nếu endpoint thực yêu cầu, retry payload cố định, xử lý mất response/conflict; không thêm header giả.
8. Upload riêng: intent → signed PUT theo header được trả → complete → kiểm READY/FAILED → signed access có hạn; cookie BE không truyền sang storage.
9. Test cases schema/service/hook và bằng chứng runtime/thiết bị; mọi khoảng trống phải được ghi rõ.
